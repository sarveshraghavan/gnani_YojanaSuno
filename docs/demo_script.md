# Three-minute demo walkthrough

1. **0:00–0:25 — Set expectations.** Open the page, select Tamil, and point out the AI disclosure, the “demo screening” label, and the instruction never to say Aadhaar or bank numbers.
2. **0:25–0:55 — Speak a sample.** Say: “என் பெயரில் இரண்டு ஏக்கர் நிலம் உள்ளது. மதுரையில் நெல் பயிரிடுகிறேன்.” Upload a clean recording or use the live microphone. Show the transcript and explain that real audio needs the locally configured Prisma provider; mocks remain the default.
3. **0:55–1:25 — Confirm facts.** The conversation asks a follow-up if required. Read the values back and confirm. Correct a detail once to show the correction turn and session memory.
4. **1:25–2:10 — Show results.** Provide remaining test slots in the form (state, district, season, notification, and pump details if demonstrating those cards). Show the deterministic result, source links, the “Unverified draft” badge, and expand “What this check did not cover.” Explain the rules engine does not declare official eligibility.
5. **2:10–2:35 — Play the answer.** With a configured supported language/voice, play the Timbre audio. If voice service is unavailable, show the localized text response and 1551 fallback.
6. **2:35–3:00 — Human next step.** Open the official scheme source and point to Kisan Call Centre 1551 / 1800 180 1551. Mention that recordings and test scores are not field validation.

## Limitations and responsible use

- This is demo screening only, not an official eligibility decision or application service.
- Eligibility rules are illustrative, explicitly unverified drafts; state notifications and windows can change.
- Evaluation scores come from a small synthetic fixture set, not farmer field recordings.
- Evon is optional. It extracts candidate slots and never decides eligibility.
- Users are told when AI is involved, and should not speak Aadhaar or bank numbers.
- Regional wording and voices need native-speaker review; official rule mapping needs an agriculture/scheme reviewer.
